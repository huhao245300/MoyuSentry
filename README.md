## 一句话定位

当你在多个项目、多个窗口之间来回切换，同时跑着 Cursor、Claude Code、Codex、CodeBuddy、WorkBuddy……**「谁在等我点确认」这件事本身就成了负担。**

MoyuSentry 是一个**菜单栏常驻的 AI Agent 状态哨兵**：它在后台持续观测本机所有 AI 编程工具，用**一个会话一行**的粒度告诉你——绿点代表正在跑，橙点代表正卡在授权门等你，蓝点代表已完成。

---

## 核心亮点

### 1. 一个会话一行 · 一屏看清全部 Agent

不同于「按项目聚合」的粗略视图，MoyuSentry 的显示粒度是**会话**：

- 悬浮窗与主窗口**同源**，同一页列出的元素与顺序完全一致，不会出现两处对不上；
- 行标识 = `路径 + Agent + 会话键` 三段式，同一项目里并行的多个 CLI 会话**不会被合并吞掉**；
- 每行前面是**各家专属图标**（厂商 logo 或语义近似的 SF Symbol），一眼就能分辨是谁。

### 2. 三色相位语义 · 急迫度优先

| 颜色   | 含义      | 是否闪烁 | 数据语义                 |
| ---- | ------- | ---- | -------------------- |
| 🟢 绿 | **运行中** | 闪烁   | Agent 正在流式输出 / 执行工具  |
| 🟠 橙 | **待确认** | 强调   | Agent 卡在授权门，**正在等你** |
| 🔵 蓝 | **已完成** | 不占灯位 | 本轮回合已结束（仅出完成圆点）      |
| ⚪️ 灰 | **空闲**  | ——   | 默认态，无任何 Agent 活动     |

- 两盏状态灯**按急迫度抢占**，完成态不占用灯位；
- 展开面板**按急迫度自动落页**：待确认 > 运行中 > 已完成，绝不让你错过卡住的会话。

### 3. 菜单栏 = 「今日已工作 X 小时 Y 分钟」

菜单栏常驻一枚小蓝点 + 累计工作时长读数。

- 数据源为**跨会话合并后的墙钟时长**，多个 Agent 并行不会重复计时；
- 「等你确认」的时间**不计入**工作产出；
- **全程 `.accessory` 激活策略**：Dock 里永远没有图标、不进 ⌘Tab —— 它是一个真正的「隐身工具」。

### 4. 18 家 Agent · 注册表驱动

新增一家 Agent = **改一个文件**（`AgentRegistry.swift`），进程识别 / 会话解析 / 相位判定 / 阻塞检测全部自动生效，没有任何 per-tool 分支散落在引擎里。

### 5. 四层证据融合 · 抗误判

单一信号必然误判——CPU 高不代表在思考，有网络连接不代表在干活。MoyuSentry 采用**多层证据融合 + 单调 OR**：

```
进程识别 → Worker 判定 → 会话来源 → 会话新鲜度 → 项目归因 → 最终相位
```

- **会话文件为最高权威**：jsonl / sqlite 里的真实回合事件，胜过任何写盘、连接或 CPU 表象；
- **常驻长连接的家族**（Cursor / Claude / Codex 等）不会因为「开着」就被判成「在干活」；
- ⚠️ 铁律：证据不足时判 `unknown`，**绝不**武断判成「已结束」——那会导致「干活时灯反而灭了」。

### 6. 「待确认」检测三档判据

识别「Agent 在等我」，按可信度从高到低取用：

1. **权威档**：会话状态文件里的 `status` / `waitingFor`（精确、无歧义）；
2. **启发式档**：jsonl 尾行是「需要授权的工具」且迟迟没有回执；
3. **兜底档**：对 tail 文本做**字段级**关键字匹配（绝不整行匹配，避免正文误伤）。

各家差异化处理：Claude Code 的子代理假结束、Codex 的提权授权、WorkBuddy 的审批弹窗不写日志、OpenCode 的交互门禁……都已单独建模。

### 7. 隐形悬浮窗（HUD）

- 常驻屏幕顶部，**悬停不展开**（只手型 + 提亮），点击胶囊才展开；
- 收起有三条路：上箭头 / 点窗外 / 底部「打开统计」——**收起 ≠ 隐藏**；
- 支持**指定落屏**（自动 / 钉住某块屏），换屏即时响应；
- 命中测试用**卡片自上报 frame** 实现，透明区域点击穿透，不吞你屏幕上任何一次点击。

### 8. 统计页 · 把「摸鱼/工作」量化

- **今日工作时长**、按项目 / 按 Agent 的时长排行；
- **口径严格自洽**：`Σ 项目时长 ≡ Σ Agent 时长`，段内间隔归给前一个事件所属项目，跨项目交错不重叠错位；
- **文件操作排行**：谁改了哪个文件、改了多少次；
- **风险评分**：敏感路径 / 危险命令（`PathGuard` + `RiskScorer`）单独成节；
- 支持**会话相位兜底**：只有会话活动、没有文件事件的家，也会按家补齐进摘要。

## 支持的 AI Agent

| 类别           | Agent                                                                                                  | 支持程度            |
| ------------ | ------------------------------------------------------------------------------------------------------ | --------------- |
| **CLI**      | Claude Code · Codex · Gemini CLI · Aider · OpenCode · DeepSeek Harness                                 | 已验收 / 待验收       |
| **IDE / 桌面** | Cursor · VS Code · Windsurf · Trae · Antigravity · Qoder · CodeBuddy · WorkBuddy · MarsCode · CodeBurn | 已验收 / 待验收 / 仅登记 |
| **扩展**       | Cline · Continue                                                                                       | 仅登记             |

> 支持程度：**已验收** = 逐项核对过；**待验收** = 已接入但允许误判；**仅登记** = 只认进程身份，靠进程 / 网络 / 回车推断。

## 隐私

- **数据 100% 留在本机**：所有观测结果写入本地 SQLite，不上传任何会话内容、代码或路径；
- 唯一的外呼是**授权状态校验**（激活与试用期判定）；
- 不读截图、不注入进程、不上传日志。

**首次启动会看到什么**

1. App **静默驻留菜单栏** —— Dock 中不出现图标，也不进入 ⌘Tab；
2. 菜单栏出现「今日已工作 0小时0分钟」，点开即可看到全部 Agent 的实时状态；
3. 屏幕顶部出现常驻胶囊（悬浮窗），**点击才展开**，且**收起 ≠ 隐藏**。
